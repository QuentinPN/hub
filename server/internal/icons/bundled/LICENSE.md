# Icônes des services embarquées

Source : [selfh.st/icons](https://selfh.st/icons) (github.com/selfhst/icons, commit
`02dd039d62a8e7132f4828e69162fca30bd43bb5`), sous licence
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Fichiers copiés sans modification.

Ce lot de départ permet d'afficher les icônes sans accès à Internet. Les autres icônes sont
téléchargées par le serveur à la première demande, vérifiées, puis gardées dans PostgreSQL
(`internal/icons`).

Les logos restent des marques de leurs éditeurs ; ils ne servent ici qu'à identifier chaque service.
